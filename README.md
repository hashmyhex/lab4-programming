# Лабораторная работа № 4. Условные операторы и задачи с ветвлениями

Практическое освоение условных конструкций и операторов выбора.

## Файлы

- task1.py: проверка чётности, деления на 3 и знака числа
- task2.py: поиск максимального из трёх чисел
- task3.py: классификация возраста пользователя
- task4.py: решение квадратного уравнения через дискриминант
- task5.py: калькулятор с оператором match и защитой от деления на ноль
- task6.py: проверка года на високосность
- task7.py: проверка существования и определение типа треугольника
- task8.py: проверка попадания точки в круг (групповая работа)
- samostoyatelnaya/from_10_to_2_8_16.py: перевод чисел из десятичной системы счисления в 2, 8 и 16-ричную

## Запуск

    python3 task1.py
    python3 group/group.py
    python3 samostoyatelnaya/from_10_to_2_8_16.py
